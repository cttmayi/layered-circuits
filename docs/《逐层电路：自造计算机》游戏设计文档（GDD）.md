# 《逐层电路：自造计算机》游戏设计文档（GDD）

## 0\. 文档总览 \& 核心定案（最终版需求锁死）

### 0\.1 游戏定位

一款**纯数字电路递进设计沙盒游戏**，无实物组装、无物理焊接故障、无PCB/3D结构模拟。玩家从最底层分立基础元件出发，逐阶段设计、封装、复用电路模块，自上而下搭建逻辑门、时序单元、运算单元、存储器、控制器，最终组装出完整可运行的自制计算机。

核心特色：**所有高级模块无独立定价，成本完全递归溯源底层基础元件，全程预算约束\+电路优化\+模块复用**，完美还原数字电路与计算机组成原理的层级构建逻辑。

### 0\.2 三大硬性规则（不可修改）

1. **纯逻辑仿真**：仅模拟数字电路逻辑、时序冲突、信号传输，无任何物理实物模拟，故障仅为逻辑错误、时序违例。

2. **全链路模块复用**：前一阶段成功设计并封装的电路模块，永久加入个人组件库，作为后阶段的核心搭建素材，所有高级器件均由低级模块堆叠构成，无系统预制成品芯片。

3. **递归成本体系**：仅最底层基础元件拥有固定单价，所有封装模块、高级器件的成本，均为内部所有底层元件成本的递归求和，无额外溢价、无单独定价。

### 0\.3 对标差异

区别于《Turing Complete》：本作**从零自建底层逻辑门**，而非系统预设门电路；新增唯一的递归成本约束玩法，核心乐趣是「功能实现 \+ 最小成本优化 \+ 层级模块化设计」。

## 1\. 核心玩法与游戏循环

### 1\.1 标准游玩循环（全关卡通用）

1. **接取任务**：获取当前关卡功能需求、最大总成本预算、仿真校验规则（基础逻辑/进阶时序）；

2. **电路设计**：从组件库拖拽基础元件或过往封装模块，完成布线、参数配置；

3. **仿真测试**：运行仿真，校验输入输出逻辑、时序稳定性，排查逻辑错误、竞争冒险；

4. **成本结算**：系统自动递归展开所有模块，统计全部底层基础元件，计算总成本；

5. **通关封装**：功能达标且成本≤预算，即可通关，将当前电路封装为全新自定义模块，永久加入组件库；

6. **优化迭代**：可重复挑战关卡，优化电路结构，减少底层元件数量，刷新最低成本记录。

### 1\.2 核心乐趣点

- **知识闭环乐趣**：所有计算机核心部件（触发器、寄存器、内存、CPU）均为玩家亲手逐层搭建，彻底理解硬件层级关系；

- **取舍博弈乐趣**：同一功能可多方案实现，高稳定性电路成本更高，极简低成本电路可能存在时序隐患；

- **积累成长乐趣**：每一关的产出都是后续高阶设计的必备素材，形成完整的个人硬件组件生态；

- **极致优化乐趣**：挑战理论最低元件数、最低成本，追求最优电路架构。

## 2\. 游戏核心系统设计

### 2\.1 元件与模块系统（核心核心）

#### 2\.1\.1 唯一底层基础元件（成本根节点）

仅以下4种元件拥有固定单价、固定信号延迟，所有电路成本、时序均溯源至此，无其他底层元件。

|基础元件|固定单价|信号延迟（时序参数）|核心用途|
|---|---|---|---|
|NPN三极管|2|1ns|构建所有逻辑门核心开关单元|
|电阻|1|0\.5ns|限流、分压，搭配三极管搭建门电路|
|二极管|1\.5|0\.8ns|单向导通、逻辑隔离、ROM阵列搭建|
|电容（时钟专用）|3|无传输延迟|搭配元件搭建时钟振荡电路，提供时序信号|

*备注：数值为初始平衡数值，可后续批量微调比例，不改动体系逻辑*

#### 2\.1\.2 自定义封装模块规则

- 模块来源：玩家通关对应关卡后，可将当前有效电路封装为自定义模块；

- 模块形态：封装后仅暴露输入、输出、控制引脚，内部电路默认隐藏（可点击溯源查看完整底层结构）；

- 复用规则：所有已封装模块永久保存在个人组件库，后续所有关卡可自由拖拽使用，无使用次数限制；

- 版本保留：同一功能可保存多个版本（标准版、极简低成本版、高稳定时序版），玩家可自由选型复用；

- 禁止逆向修改：已封装模块不可直接修改内部电路，如需优化需重新搭建新版本。

### 2\.2 递归成本计算系统（核心核心）

#### 2\.2\.1 核心逻辑

任何自定义模块、复合电路，无独立成本，系统自动**递归拆解至最底层三极管、电阻、二极管、电容**，累加所有基础元件单价，得出总成本。

#### 2\.2\.2 计算示例

- 非门 = 2三极管 \+ 3电阻 → 总成本 = 2×2 \+ 3×1 = 7

- 与非门 = 4三极管 \+ 4电阻 → 总成本 = 4×2 \+ 4×1 = 12

- D触发器 = 6个与非门 → 总成本 = 6×12 = 72（自动递归拆解所有底层元件）

- 8位寄存器 = 8个D触发器 → 总成本 = 8×72 = 576

- RAM存储器 = 若干寄存器 \+ 译码器 \+ 控制逻辑 → 总成本全量递归累加

#### 2\.2\.3 结算规则

- 关卡通关唯一硬性条件：**电路功能完全正确 \+ 总成本≤关卡预算**；

- 功能正确但成本超标：判定失败，需优化电路、删减冗余元件；

- 成本达标但逻辑错误：判定失败，需修复布线、逻辑漏洞；

- 优化评分：通关后根据「实际成本/预算上限」计算得分，比值越低评分越高。

### 2\.4 组件库管理系统

## 4\. 关卡挑战类型（丰富玩法维度）

### 4\.1 标准通关关卡

基础主线关卡，要求实现指定电路功能，且总成本不超过预设预算，通关解锁对应封装模块，推进主线流程。

### 4\.2 成本优化挑战关

无硬性预算上限，功能固定，核心目标为**最小化底层元件总成本**，记录全局最低成本排名，鼓励玩家钻研极简电路方案。

### 4\.3 时序稳定挑战关

强制开启硬核时序模式，固定总成本上限，要求电路在指定高频时钟下无时序错误，平衡成本与稳定性。

### 4\.4 复古复用挑战关

限制玩家仅可使用早期低版本模块，禁止使用后期优化模块，考验玩家基础电路设计功底。

### 6\.1 预算数值逻辑

- 分级仿真：小规模电路全量仿真，大规模整机电路采用模块黑盒仿真，平衡真实度与流畅度。
