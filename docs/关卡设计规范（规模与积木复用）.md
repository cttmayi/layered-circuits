# 关卡设计规范（规模、循序渐进与积木复用）

> 状态：**设计规范文档**，与《关卡循序渐进设计蓝图（待审核）》互为补充——
> 蓝图管「难度曲线」（哪里断档、加几级台阶），本文档管「答案规模与模块复用」（每关答案该多大、该用哪些已解锁积木）。
> 先立规矩，再据此修订现有内容与新增关卡。

## 一、核心口径：标准答案 ≤ 15 个「可见盒子」

**定义**：`15 个以内` = 该关**门版参考解**（一键出答案默认加载的那个）在画布上的**顶层可见盒子数**（元件盒 + 模块盒都算）。玩家加载答案后一眼能数过来、能看懂结构。

**适用与豁免**：

| 对象 | 是否受 15 限制 | 理由 |
|------|----------------|------|
| 门版答案（一键出答案默认） | ✅ 必须 ≤ 15 | 玩家主要看到的就是它；答案要可读、可学 |
| 元件版参考解（隐藏的性能优化解） | ❌ 豁免 | 默认不展示；只有玩家主动选/更优时弹窗，属「性能展示」 |
| 教学关（classroom + seedDoc 引导搭） | ❌ 豁免 | 玩家一步步被引导搭，不是整块看答案 |
| 模块详情弹窗里的内部电路 | ❌ 豁免 | 可无限下钻（双击模块展开，Feature 2），不占主画布 |

**为什么 15**：参照「工作记忆 + 一张截图讲清楚」的经验线。190 个盒子没人能看懂，15 个左右配合「双击下钻」刚好讲清一级结构。

> **已批准的例外**（答案即教学内容 / 终局架构，均需在测试 EXEMPT 集同步登记）：
> - **s3-display / s3-seg-de / s3-seg-fg（段码×3，门版 19 / 18 / 19 盒）**：原七段译码器关（43 盒）按「每段自包含」拆成 3 关——s3-display 段码·abc（19 盒）→ s3-seg-de（18 盒）→ s3-seg-fg（19 盒）。每关输入输出都是可读的（BCD → 哪几根段线亮，0-9 真值表）；不做「共享中间项」模块（那会让第 1 关变成 13 个玩家看不懂的中间信号）。盒数超 15 属**答案即教学内容豁免**：NAND 链 n 项 = 2n-3 门是数学下限，砍共享后每关至少 18 门；【七段译码器】教学积木保持共享积项的 43 门结构（成本 860），供 calc 显示控制与 s3-display2 门版复用。
> - **s3-or-chain（多输入或门关）**：或门原理 = 二极管并联，多输入 = 更多二极管并联（或门级联）。本关产出【多输入或门】积木，是编码器 or 矩阵的砖块；门版 = 元件版直接展示（5 元件 ≤ 15，无豁免）。
> - **s3-calc（简易计算器组装关）门版 = 29 盒**（数字键盘编码器 + 数字输入寄存器 + 运算控制 + 八位寄存器 + 2×BCD→二进制 + 7×异或 + 8×全加器 + 二进制→BCD + 显示控制）。终局组装关的架构由 8 位 ALU + 控制 + 显示决定，粗粒度下限 ≈23 盒（见 §五实施记录），超出 15 属架构豁免。
> - **s3-display2（数码管显示关）无需豁免**：2 盒达标（2×【七段译码器】模块实例，教学积木共享积项 43 门）。它是段码拆关链的收尾——玩家手工可拖 2 组【段码abc】【段码de】【段码fg】（6 盒）或一键出答案 2×【七段译码器】；教学点 = 模块复用/位宽扩展。

## 二、设计原则

1. **小步走**（继承蓝图 §二）：每关只教一个新概念，元件/成本平滑增长。
2. **每关产出恰好一个可复用模块**：玩家通关 = 该电路被封装成模块进组件库（`App.tsx:987` wrapModule + addModule）。下一关的答案必须优先复用上一关产出的模块。
3. **答案两级分层**：顶层 ≤ 15 个「已认识的积木」（玩家已解锁模块 / 教学内容积木 TEACHING_MODULES）；内部结构靠**双击展开**查看，不摊平到主画布。
4. **不重复内联**：答案里同一单元出现 ≥ 3 次时，必须封装成模块再复用（禁止把加3单元 × 14 内联、把 D 触发器拆回 2 锁存器这种操作）。
5. **组装关 = 粗粒度答案**：压轴合成关（如计算器）的答案就是「拼几个大模块」，盒子数反而最少（≈5–9），教学点是组装顺序，不是内部细节。

### 时序预算（传播延迟）取值规则

- 卡片/合同只在关设了 `timingBudgetPs` 时显示「传播延迟」；预算 ≈ **2 × 参考解实测延迟**（取整），参考解自己拿 3 颗时序星（ratio ≤ 0.5）。
- 时序只影响星级，不影响过关（用户定稿：延迟与成本一样是性能指标）。
- **大电路 / 带时钟的存储类关不设预算**：每次判定都要全仿真实测延迟（时钟电路要跑完 1ms 稳态窗口 ≈ 100 个时钟周期），
  reg-8 / 数字输入寄存器 ≈ 0.4s、calc ≈ 1s/次，会让「交付验收」明显卡顿。教学点也不是时序。目前 4 关豁免：
  s3-bin2bcd（14 级链 163ms）、s3-reg-8、s3-digit-entry、s3-calc。其余 26 个主线关全部显示传播延迟。

## 五、违规关修复预案

### 预案 1：加3单元封装（止血 bin2bcd / calc）

把 `plus3ModulesInto` 的 13 门单元封装成内容积木 `加3单元`（命名遵循教学内容，hash 由内容确定）。

- **bin2bcd 门版** = 14×【加3单元】 + 8 复位电阻 = **22 盒**。
- **calc 门版**内嵌 bin2bcd 段 = 22 盒（不再 ×13 展开）。
- 双击任一个【加3单元】可展开看内部 13 门（Feature 2 正好支撑）。
- **注意**：22 仍略超 15——两个出口：① 把初始置零并入单元内部（单元自带弱下拉，保证首级输入默认 0；**设计细节，实现时需验证判定语义不变**）；② 若走预案 2 拆关，加3单元本身就是玩家产出模块，bin2bcd 顶层 = 14 盒。

### 预案 2：拆关（根治 bin2bcd 教学）

- 新增 `s3-plus3`「加 3 修正单元」关：教 double-dabble 的核心一步（≥5 加 3），产出【加3单元】模块；
- 原 bin2bcd 关答案 = 14×【加3单元】+ 复位 = 14 盒 ✅；
- 玩家先学会「加 3」这个新概念，再做整段 double-dabble，符合「小步走」。

### 预案 3：reg-8 复用 D触发器

- 把【主从 D 触发器】补进内容积木集（复用 s2-dff 的教学结构，不进玩家库、只作答案砖块，与 D锁存器并列）；
- reg-8 门版 = 8×【D触发器】 + 1 非门（时钟反相）= **9 盒** ✅。

### 预案 4：calc 改组装关（粗粒度）

calc 的教学点是「拼模块」，答案按**粗粒度**重组：
`2×【BCD→二进制】+ 1×【8位加法器】+ 1×【二进制→BCD】+ 1×【8位寄存器】+ 时钟反相` ≈ **6 盒** ✅。
每个盒子双击下钻看内部（bcd2bin 内部是 12 全加器、bin2bcd 内部是 14 加3单元……）。需要新增内容积木：`BCD→二进制`、`二进制→BCD`、`8位寄存器`（或直接让 calc 答案引玩家封装版本）。

## 六、验收标准（可写进 CI）

1. **规模断言**：新增测试对每个有关卡，断言 `teachingSolutionOf(...)` 顶层 unit+module 盒数 ≤ 15（门版为 0 的关断言元件版 ≤ 15；教学关豁免）。
2. **复用断言**（可选强化）：统计答案里各类模块实例数，禁止同一结构 ≥ 3 次的内联展开（用「模块种类覆盖 TEACHING_MODULES 复合积木」间接保证）。
3. **新增关检查清单**：新关必须满足——参考解成本 = optimalHalf（快照校准）、延迟线 = 实测 ×2、门版盒子数 ≤ 15、答案只含「玩家已解锁模块 ∪ TEACHING_MODULES」、通关产出一个可复用模块且被后续关复用。

## 九、新增：按钮 / 七段数码管器件与测试关

> **器件**：组件库（电源与端口组）新增可放置「按钮」与「七段数码管」——
> 按钮 = 瞬时按键输入端口（按住 = 电平 1、松开归 0）；数码管 = **7 位段码显示输出端口**（bit0=a..bit6=g，每根线点亮对应段；**电路自己把 BCD 译成 7 段信号**，渲染层不再内部译码——s3-display 起 3 关教段码译码（abc → de → fg），s3-display2 教「把译码器当模块复用两次」）。
> 二者与关卡锁定端口同构（同一组 Sym 字段），判定/成本/仿真零改动，导出后即普通端口；沙盒（自由搭建）可自由放置，关卡模式下与输入/输出端口一样锁定。
>
> **测试关**：用新器件验证「记忆」与「显示」两个能力。

| 关卡 | 门版盒子数 | 成本（optimalHalf） | 达标 | 构成 |

**键盘布局（inputGridCols）**：多位按键关（s3-encoder 3 列、s3-calc 4 列）声明 `inputGridCols` 后，
`docForLevel` 把输入端口按 `ports` 数组顺序行优先排成键盘式网格（宽 110/列、高 96/行）；
缺省（无该字段）保持历史单列竖排（200 + i×140），既有关卡的画布坐标与测试不受影响。

**实现要点**：或非门交叉耦合的 SR 锁存在保持态（双输入弱电平）会在二极管下拉处等强冲突 → sim 判定组合振荡（q=X）；
参考解与门版均改用「非门反相 + 与非门交叉耦合」（s2-d-latch 同款已验证结构）。s2-btn-latch 是时序电路，须声明
`unlock.kind = 'seq'`（判定器按它区分组合/时序），并顺带解锁「按钮锁存器」积木。
