## 快速开始

```bash
pnpm install
pnpm dev          # 启动电路工作台（Vite dev server）
pnpm build        # 产出单文件 demo：apps/studio/dist/index.html（双击即可打开）
pnpm check        # typecheck + lint + 全部测试
pnpm test         # 只跑测试
```

工作台操作：左侧点元件 → 画布上点一下放置；点两个引脚连线；点输入符号切换 0/1（Alt 循环 X/Z）；
空白处拖动平移、滚轮缩放；`R` 旋转、`Delete` 删除、`Ctrl/Cmd+Z` 撤销。
右侧实时显示成本、内容哈希、端口电平、接线检查与真值表；「封装为模块」后可当元件复用，成本自动递归累加。

## 关卡模式（阶段 1 + 阶段 2 + 挑战关，共 13 关）

打开就是**接单模式**：进关先弹一张居中的**「新委托」**对话框 —— 客户、需求、合同之外，
**支线单直接在对话框里选**（接/不接），点「开工」后如果图纸还没测出来，会**直接进入居中的「黑盒侦察」对话框**：
用测试仪逐组测输出、自己填需求表、核对图纸，全部操作都在对话框里完成；
验收交付同样是居中的「验收报告」对话框（评级/利润/星级/支线奖金 + 下一单）。
每一关都是一张**委托单**（委托方 + 人话需求 + 合同条款：款项 / 交期 / 禁忌）。（委托方 + 人话需求 + 合同条款：款项 / 交期 / 禁忌），
左侧还有一面**任务墙**（按章节列出所有委托、进度与星级）。图纸不是白给的：客户送来的图纸折了角，
输出列看不清 —— 用**黑盒测试仪**逐组测出结果、自己填进需求表、核对通过才算「自主测绘」（也可以直接看答案，会被记在账上）。
每一张委托单还挂着**支线单**（可选）：**加急单**（关键路径压到 75%）与**手工单**（不许用组件库模块，
早期关卡换成**省料单**要求做到对标成本），达成后拿额外奖金，验收时按支线条件真判定。
搭好电路点「交付验收」，
右侧**验收台**逐行对比你的输出与要求并给出错误原因；通过后点「交付并封装为【非门】」，
你会看到**封装过场**（电路压成一颗芯片落进组件库）与**结算页**：客户验收结论、S/A/B/C 评级、
客户付款 − 材料费 = **本单利润**、钱包余额、三星评价（功能 / 成本 / 时序）。
模块进了**全局组件库**（跨关卡保留），下一关直接当元件用 —— 这就是「接单 → 搭门 → 封装 → 复用 → 成本递归」的核心循环。
钱不是纯数字：**通关数 + 钱包余额**决定你的称号（学徒 → 维修铺师傅 → 高级技师 → 研究所特聘 → 总工程师）；
钱包还能在**工具铺**花掉 —— 买**测试探针**（黑盒侦察点「测」自动记录）和**示波器游标**（波形上点两下读 Δt）。
刻意不卖「一键测完」：工具只省操作，不替你玩。

| 关卡 | 最优成本 | 预算 | 硬核时序 | 素材 |
|---|---|---|---|---|
| 非门 / 与门 / 或门 | 4 / 4 / 4 | 5 | 2.5 / 2.0 / 2.0 ns | 只能从底层元件手搭（阶段 1 不开放电容） |
| 与非门 / 或非门 | 7 / 8 | 8.5 / 10 | 3.5 / 4.0 ns | 可用自己的组件库 |
| 异或门 / 同或门 | 28 / 32 | 34 / 38.5 | 7.0 / 9.0 ns | 可用自己的组件库 |
| SR 锁存器 / D 锁存器 | 14 / 32 | 17 / 38.5 | — | 可用自己的组件库（阶段 2） |
| 主从 D 触发器 | 68 | 82 | ≤20 ns + 20 MHz | 可用自己的组件库（阶段 2） |
| 异或门·复古版（复古复用） | 28 | 34 | 7.0 ns | **禁用【与非门】模块**，只能用早期手段 |
| D 触发器·极限成本（成本挑战） | 68 | 无上限 | ≤30 ns | 不设预算，比谁更省，成绩进重挑战榜 |
| D 触发器·高频挑战（时序挑战） | 68 | 82 | ≤20 ns + 20 MHz，**强制硬核** | 可用自己的组件库 |

判定：**功能全部符合** + **成本 ≤ 预算**，阶段 1 的组合关卡还要求「不是时序电路」。
硬核工程模式（工具栏「科普 / 硬核」切换）用同一份电路再判一次时序：
关键路径、**空翻次数**（每个时钟窗口内输出最多跳几次）、**建立/保持时间**（真仿真扫描实测）、
以及「数据路径 + 建立时间 ≤ 时钟周期」—— 面板上勾选「波形」就能看到端口阶梯图，
时钟高电平期间改数据而输出纹丝不动，就是「无空翻」的可视证据。

成本越接近最优得分越高（成本 ≤ 满分线 = 100 分），进度与组件库存 localStorage，可以反复挑战刷新最低成本。

**组件库与成绩面板**（右侧）给出：每个模块的各版本与**溯源树**（这一版用了哪些下层模块、产出自哪一关）、
每关的历史最低成本 / 得分 / 尝试次数（标出是否已经做到「已知最省」），以及**存档导出 / 导入**（整包 JSON）。

不想被约束就用「自由模式」当纯沙盒。

### 内容基建：改关卡不用改代码

```bash
pnpm solve                                             # 打出「声明最优 vs 求解器结论」对照表
pnpm lc-level tools/level-editor/specs/s1-majority.json /tmp/s3-level.ts   # spec → 已验收关卡
```

`tools/opt-solver` 会发现「关卡声明的最优其实不是最省」（例如或非门 16 → 14、异或门 56 → 42），
`tools/level-editor` 则把「写真值表 → 出关卡 + 参考解 + 预算」压到几分钟，见 `tools/level-editor/README.md`。

> 并改成工作区内的绝对路径，即可把 pnpm store 与 npm cache 放在项目内。

## 一段代码看懂内核

```ts
import { NetlistBuilder, Simulator } from '@lc/sim-core';

const b = new NetlistBuilder();
const IN = b.node('IN'), VCC = b.node('VCC'), GND = b.node('GND');
const B1 = b.node('B1'), A = b.node('A'), OUT = b.node('OUT');
b.power(VCC, 1); b.power(GND, 0);
b.res(IN, B1, 'R1');      // 输入限流
b.npn(A, B1, GND, 'Q1');  // 共射反相级
b.res(VCC, A, 'R2');      // 上拉
b.npn(VCC, A, OUT, 'Q2'); // 射极跟随器输出级
b.res(OUT, GND, 'R3');    // 输出下拉
b.input(IN, 'in'); b.output(OUT, 'out');
const net = b.build();    // 2 三极管 + 3 电阻 = 成本 7

const sim = new Simulator(net, { mode: 'logic' });  // 或 mode: 'timing'（1ns/0.5ns/0.8ns 延迟）
sim.setInput('in', 1);
console.log(sim.readPort('out')); // 0
```

## 语义速查

| 规则 | 内容 |
|---|---|
| 信号 | `0` = 悬空 Z；否则 `(强度 << 2) \| 逻辑值`，逻辑值 0/1/X，强度 WEAK(1)/STRONG(2) |
| 归约 | 强驱动胜；多个强驱动冲突 → X（短路错误）；多个弱驱动对拉 → X（分压不确定） |
| 通路元件 | 电阻/三极管/二极管只向**外部驱动更弱的一侧**传递电平（避免浮空孤岛伪稳态） |
| 三极管 | 基极 1 = 导通（双向），0 = 截止，Z = 截止 + 警告，X = 注入弱 X |
| 二极管 | 阳极确定为 1 且阴极不为 1 时导通，**单向**（逻辑隔离） |
| 电容 | 只计成成本，不参与逻辑仿真 |
| 模式 | `logic` 忽略延迟、迭代到收敛（不收敛 = 组合环/振荡）；`timing` 按 ps 整数延迟做事件驱动 |
